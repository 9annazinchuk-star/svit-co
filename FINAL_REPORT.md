# Svit&Co v4 — короткий звіт

## Змінено
- Головний екран із пріоритетом «Ремонт квартир під ключ» / “Complete Apartment Renovation”.
- Початковий порядок послуг: ремонт під ключ, душові кімнати, туалети, далі інші послуги; душові й туалети окремі.
- «Про майстра» → «Наша команда» з одноразовою повторно-безпечною міграцією старого запису.
- Адмін-панель розбита на окремі розділи з власним збереженням.
- Керування послугами, проєктами, командою, секціями, медіатекою, контактами, сповіщеннями, брендом і SEO.
- Динамічна UA/EN форма заявки з Phone / WhatsApp / Viber / Telegram / Email.
- Заявка спочатку зберігається, потім створюються завдання сповіщень.
- Постійна черга сповіщень із retry, журналом спроб і ручним повтором.
- Серверні адаптери: Telegram Bot API, Resend Email API, Twilio SMS, офіційний WhatsApp Business Cloud API.
- Секрети читаються лише зі змінних середовища.
- Media Library із перевіркою фактичного типу файлу, alt UA/EN та перевіркою місць використання перед видаленням.
- Мобільні виправлення, перенесення довгих текстів і prefers-reduced-motion.
- render.yaml і Persistent Disk /var/data збережені без змін.

## Де редагується контент
`/admin` → Огляд, Заявки, Головний екран, Послуги, Проєкти та портфоліо, Команда, Розділи сторінки, Медіатека, Контакти та способи зв’язку, Сповіщення, Бренд і загальні налаштування, SEO та метадані.

## Перевірки
- `node --check server.cjs` — пройдено.
- `node --check public/js/app.js` — пройдено.
- `node --check public/js/admin.js` — пройдено.
- `node tests/v4-static.mjs` — пройдено.
- `render.yaml` звірено з початковим архівом: файл ідентичний.
- Повний runtime smoke-test у цьому робочому середовищі не завершився, бо `npm ci` не зміг докачати залежності в межах доступного мережевого/часового ліміту контейнера. Самі залежності зафіксовані в `package-lock.json`; на Render використовується штатний `npm ci`.

## Що власниця ще повинна підключити
Без реальних ключів зовнішні канали не можна чесно назвати підтверджено доставленими:
- Telegram: `TELEGRAM_BOT_TOKEN` + chat_id в адмінці.
- Email: `RESEND_API_KEY`, `RESEND_FROM_EMAIL` + email одержувача.
- SMS: Twilio `ACCOUNT_SID`, `AUTH_TOKEN`, `FROM_NUMBER` + номер одержувача.
- WhatsApp: Meta Cloud API access token, Phone Number ID, затверджений template + номер одержувача.

Для локальної перевірки черги без зовнішніх сервісів передбачено `NOTIFICATION_TEST_MODE=1`.
